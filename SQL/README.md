## 📋 SQL Command Quick Reference Summary

| Category | Commands |
| :--- | :--- |
| **DQL (Data Query Language)** | `SELECT`, `FROM`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`, `LIMIT`, `OFFSET`, `DISTINCT`, `AS` |
| **DML (Data Manipulation)** | `INSERT INTO`, `UPDATE`, `DELETE FROM`, `MERGE` / `UPSERT` (`ON CONFLICT`) |
| **DDL (Data Definition)** | `CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`, `TRUNCATE`, `CREATE VIEW`, `CREATE INDEX` |
| **DCL (Data Control)** | `GRANT`, `REVOKE` |
| **TCL (Transaction Control)** | `COMMIT`, `ROLLBACK`, `SAVEPOINT`, `RELEASE SAVEPOINT` |
| **JOIN Types** | `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL JOIN`, `CROSS JOIN`, `SELF JOIN` |
| **Set Operations** | `UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT` / `MINUS` |
| **Window Functions & CTEs** | `WITH`, `WITH RECURSIVE`, `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LAG()`, `LEAD()`, `QUALIFY` |
