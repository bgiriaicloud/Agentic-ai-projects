# Machine Learning Engineer Interview Preparation Guide (Google Edition)

This folder contains the complete study guide and reference materials for preparing for **Google Machine Learning Engineer (MLE)** technical and system design interviews.

---

## 📖 Primary Study Guide Volumes

* 📄 [**`ml_engineer_part1.md`**](file:///Users/biswanathgiri/GenAI%26AgenticAI%20-Learing%20Roadmap/MLEnginer_Guide/ml_engineer_part1.md) (**Questions 1 to 100**):
  - **Section 1: ML Fundamentals & Mathematical Foundations (Q1 – Q30)**: Bias-Variance Tradeoff, Gradient Descent variants (SGD, Momentum, Adam, AdamW), Loss Functions (BCE, Focal, Triplet), Regularization (L1, L2), Vanishing/Exploding Gradients, He/Xavier Initialization, PCA, SVD, Precision/Recall/ROC-AUC/PR-AUC, MLE vs MAP, KL Divergence, Learning Rate Warmup.
  - **Section 2: Classical Machine Learning & Feature Engineering (Q31 – Q60)**: Logistic Regression, Decision Trees (Gini vs Entropy), Random Forests, Boosting (XGBoost, LightGBM, CatBoost), Clustering (K-Means++, DBSCAN, Hierarchical), SVM & Kernel Trick, One-Hot/Ordinal/Target Encoding, Target Leakage, SHAP Values, Naive Bayes, Scikit-Learn Pipelines, t-SNE vs UMAP, SMOTE, Isolation Forest, VIF Multicollinearity.
  - **Section 3: Deep Learning & Transformer Architectures (Q61 – Q100)**: MLPs, Backpropagation Chain Rule, Activation Functions (Sigmoid, Tanh, ReLU, GELU, SwiGLU), BatchNorm vs LayerNorm, CNNs (Stride, Padding, Pooling), ResNets & Residual Skip Connections, LSTMs (Cell states, Gates), Transformer Self-Attention ($Q, K, V$), Scaled Dot-Product, Multi-Head Attention, Positional Encodings (Sinusoidal vs RoPE), RMSNorm, Multi-Query (MQA) & Grouped-Query Attention (GQA), Dropout, VAEs, GANs, Diffusion Models, KV Cache, FlashAttention, Mixed Precision (FP32, FP16, BF16), Vision Transformers (ViT), Contrastive Learning (SimCLR/CLIP).
