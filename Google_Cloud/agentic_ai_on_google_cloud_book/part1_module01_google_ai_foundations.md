## 1.1 The Research Heritage of Google AI

Google's AI innovations have defined the modern era of machine learning and large language models:

```
┌────────────────────────────────────────────────────────────────────────┐
│                   GOOGLE AI HISTORICAL MILESTONES                      │
├────────────────────────────────────────────────────────────────────────┤
│ • 2013: Word2Vec (Mikolov et al.) - Vector embeddings for words.       │
│ • 2016: AlphaGo (DeepMind) - Defeated world champion in Go via RL.     │
│ • 2017: Transformer ("Attention Is All You Need") - Modern LLM base. │
│ • 2018: BERT - Bidirectional encoder representations for NLP.          │
│ • 2020: AlphaFold - Solved 50-year protein folding grand challenge.   │
│ • 2023: Gemini 1.0/1.5 - First natively multimodal foundation model.   │
│ • 2024+: Gemini 2.0 - Agentic core with native audio/vision & 2M ctx.  │
└────────────────────────────────────────────────────────────────────────┘
```

## 1.3 Core Paradigms Defined for Google Cloud Practitioners

1. **Foundation Models**: Ultra-large models (Gemini 2.0 Pro/Flash) pre-trained on diverse multimodal datasets.
2. **Grounding**: Connecting model outputs directly to verifiable Google Cloud data stores (BigQuery, GCS) or Google Search.
3. **Agentic Agency**: Moving beyond static question-answering to autonomous multi-step planning, tool invocation, and self-reflection.
